# #data-curation

Archive coverage: 2025-05-15–2026-09-22 (UTC); 903 messages, including 390 thread replies. [Open channel in Discord](https://discord.com/channels/1354881461060243556/1368297424086499359).

## Discussion and lessons

- An initial SFT-data contamination report needed tuning: KernelGym examples were flagged against Terminal-Bench because they shared ordinary PyTorch import boilerplate. Exact overlap scores require inspecting the matched span before labeling a dataset contaminated. [Report](https://marin-discord.pages.dev/#1368297424086499359/1549916057580474409); [false-positive example](https://marin-discord.pages.dev/#1368297424086499359/1549917870551466135).
- OpenThoughts data generation compared teacher size and response length instead of assuming that a stronger teacher or longer trace always helps. The planned paired experiment fine-tuned the same student on 30,000 math examples from Qwen3-32B versus Qwen3-235B-A22B teachers. [Discussion](https://marin-discord.pages.dev/#1368297424086499359/1458524762090242179).
- One rejection-sampling test drew eight answers from a smaller teacher and kept an answer matching a larger teacher's final answer. It modestly improved over either a random smaller-teacher sample or the larger teacher alone; the result was limited to that student/task setup. [Discussion](https://marin-discord.pages.dev/#1368297424086499359/1476381841345744961).
- Synthetic reasoning data can fail at the serialization boundary: a teacher sometimes emitted malformed thinking blocks, and the vLLM reasoning parser affected what the student actually saw. Template and parser checks therefore precede interpreting model-quality differences. [Discussion](https://marin-discord.pages.dev/#1368297424086499359/1478196842285236234).
- For agent data, trajectory diversity and verifiability were treated as separate requirements. SWE-ZERO's first 1,000 rollouts had 87.4% unique bash commands under its stated similarity threshold; TaskTrove later needed verifiers for 43 Harbor-format datasets before those tasks could be used as reliable RL feedback. [SWE-ZERO](https://marin-discord.pages.dev/#1368297424086499359/1492293100058706011); [TaskTrove](https://marin-discord.pages.dev/#1368297424086499359/1529499435321790555).
- Verifier design should expose the task and answer format without leaking the answer. Participants recommended separating deterministic RL-verifiable tasks from LLM-judged tasks, since their feedback has different failure modes. [Discussion](https://marin-discord.pages.dev/#1545689065347620955/1547046085799976960).
