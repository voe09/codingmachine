# #data-curation

Archive coverage: 2025-05-15–2026-09-22 (UTC); 903 messages, including 390 thread replies. [Open channel in Discord](https://discord.com/channels/1354881461060243556/1368297424086499359).

## Discussions and learnings

- The channel connected open-data sourcing, synthetic reasoning and agent trajectories, teacher choice, licenses, and benchmark contamination. OpenThoughts/LAION collaboration compared teachers and planned parallel sample generation. [Source](https://marin-discord.pages.dev/#1368297424086499359/1458524762090242179).
- SWE-ZERO reported 1,000 initial trajectories with diversity checks. Later TaskTrove discussion highlighted missing Harbor-format datasets and verifier coverage, showing that collection size alone does not make agent data trainable. [Source](https://marin-discord.pages.dev/#1368297424086499359/1492293100058706011).
- An initial SFT-data contamination report needed tuning: KernelGym examples were flagged against Terminal-Bench because they shared ordinary PyTorch import boilerplate. Exact overlap scores require inspecting the matched span before labeling a dataset contaminated. [Report](https://marin-discord.pages.dev/#1368297424086499359/1549916057580474409); [false-positive example](https://marin-discord.pages.dev/#1368297424086499359/1549917870551466135).
