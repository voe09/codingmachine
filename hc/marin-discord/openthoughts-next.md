## From SFT replication to an open agent-data program

The Marin/OpenThoughts collaboration began with two concrete contributions: repeat SFT experiments across base models, including larger dense and MoE checkpoints, and investigate which teacher generates the most useful training trajectories. A Qwen 8B replication was a lower-risk first step before transferring a recipe to Marin models. Candidate traces included a 32k-context collection and a 131k-context agent-sandbox collection, so sequence length was a data and serving cost as well as a model capability. [Collaboration scope](https://marin-discord.pages.dev/#1484315476325826660/1484316005097279538) · [Trace candidates](https://marin-discord.pages.dev/#1484315476325826660/1484324063840043210).

By August, the work included RL-stack validation for Qwen base and SFT checkpoints on GSM8K and easier TaskTrove environments. The immediate success criterion was an upward reward curve, with hyperparameter search and base-versus-SFT comparison following after that basic validation. Researchers cautioned that expecting small-model RL to outperform a strong distillation recipe could be unrealistic; they proposed narrowing broad aspirations into feasible, measurable goals such as a reproducible tool-use behavior or matching a stronger teacher's reward on defined tasks. A pass@k probe was suggested before spending RL compute on tasks the base model could not solve even with many samples. [RL validation plan](https://marin-discord.pages.dev/#1537145463399252091/1537174081122599053) · [Goal-setting discussion](https://marin-discord.pages.dev/#1539704940988203118/1539998023558500412) · [Reachability probe](https://marin-discord.pages.dev/#1539704940988203118/1539714678027059252).

## Task quality and agent failure modes

TaskTrove was conceived as a reproducible source of agentic environments, not merely a list of prompts. Four primary input streams were selected for integration: agent skill files, taxonomy-driven web search, recorded terminal sessions or trajectories, and executable Git repositories. The group wanted generation code alongside generated tasks where possible so the dataset could be regenerated and scaled; adaptive task evolution was a later phase. These were priorities and open implementation questions, not demonstrated training gains. [Data breakout](https://marin-discord.pages.dev/#1484315476325826660/1547671961851662346).

Agent evaluation showed why a binary reward hides different behaviors. In one failure analysis, a model ran self-checks in 44 of 62 failed trials but submitted fabricated output in 19, including invented artifacts or hardcoded answers. A Qwen comparison fabricated less often in the reported samples but skipped checks more frequently. Thus “tests itself” and “reports truthfully” need separate measurements, and a verifier must examine actual task state rather than trust the agent's claims. [Failure analysis](https://marin-discord.pages.dev/#1547290012708634686/1547315385810948188).
