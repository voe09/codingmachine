## What transfers from text modeling—and what does not

The project began with familiar language-model questions: parameter scaling, repeated epochs on limited data, and data scaling. A plant-DNA pilot used a causal LM to establish a simple baseline, while later work considered masked or bidirectional objectives because biological use cases do not always align with left-to-right generation. The team deliberately wanted to start from standard model and schedule choices, then measure where DNA required departures. [Initial scaling agenda](https://marin-discord.pages.dev/#1418673157585502370/1421280339707428884) · [Pilot and objective questions](https://marin-discord.pages.dev/#1418673157585502370/1422730578242965565) · [IsoFLOP plan](https://marin-discord.pages.dev/#1418673157585502370/1442534344622215178).

Genomic input has very different local statistics from prose. Runs of tens or hundreds of the same base can occur, depending on species and preprocessing, while many existing DNA models use a vocabulary close to the four bases plus special tokens. This changes token count, context requirements, and potentially attention stability. Animal-promoter sweeps therefore compared causal versus masked objectives, model size, repeat downweighting, and sliding-window attention rather than assuming a text-LM default. [Sequence statistics](https://marin-discord.pages.dev/#1442534344622215178/1443099373432209408) · [Promoter sweep](https://marin-discord.pages.dev/#1418673157585502370/1448363912092192939).

## Loss versus biological utility

Several participants warned that better held-out sequence loss need not imply a better zero-shot biological predictor. Protein-model examples showed cases where scale improved validation loss and post-fine-tuning performance but worsened a zero-shot fitness score. MarinDNA later reported a similar-looking missense-variant pattern: likelihood-based zero-shot performance degraded with scale in its tested regime, while a supervised linear probe improved. This is not a contradiction if the representation gets more useful while a particular unsupervised scoring rule becomes less aligned with the downstream label. [Cross-domain warning](https://marin-discord.pages.dev/#1418673157585502370/1432595415076831232) · [Linear-probe result](https://marin-discord.pages.dev/#1418673157585502370/1521988242038198313).

The group also questioned whether arbitrary train/test splits or ordinary log-likelihood best measured variant effects, and developed an observatory with benchmark leaderboards and nucleotide-dependency visualizations. One promoter model with strong Mendelian-variant scores also showed dependency maps aligned with known transcription-factor binding sites, an interpretability cross-check rather than independent causal proof. A species-prefix experiment on 16,100 Mendelian variants changed some frozen-checkpoint scores but did not establish a macro-AUPRC improvement; it measured prompt sensitivity, not whether tag-conditioned pretraining would help.
