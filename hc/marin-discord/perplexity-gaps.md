# #perplexity-gaps

Archive coverage: 2026-06-11–2026-06-16 (UTC); 21 messages, with no thread replies. Every exported message body was reviewed chronologically. [Open channel in Discord](https://discord.com/channels/1354881461060243556/1514477129134247946).

Perplexity-gap heatmaps compared Marin with another model on deterministic “circuit” tasks, including arithmetic, base conversion, and string manipulation. The author read some of Qwen's advantage as stronger code sense and noted apparently strong conversion/arithmetic behavior; string operations were intended partly as a probe of what a model knows about the *content of its tokens*. These were interpretations of diagnostic examples, not a validated measure of reasoning ability. The dashboard was assembled from experiment scripts and prior visualization work; an apparent failure of another agent to find the files was later corrected when its user noticed it was in an old worktree. The JSON discussion showed why lower likelihood on raw GitHub files did not, by itself, identify a single missing skill. One participant read the heatmaps as Marin failing to model JSON delimiters and structure; another asked whether messy Stack v2 JSON values were a poor diagnostic compared with clean synthetic graph/reasoning examples. In-context learning versus direct format knowledge was proposed as a possible explanation, explicitly without proof. A proposed BibTeX test would use partial entries for known papers—such as completing venue or authors—to make the target more interpretable, but no result appears in the archive. The lesson is to design controlled completions with meaningful fields and separate structural syntax, content prediction, and prompt-context effects before treating a perplexity gap as a data-selection rule.
