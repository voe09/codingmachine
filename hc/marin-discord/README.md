# Marin Community Discord history

Sourced channel summaries for the public Marin Community Discord server ([server ID](https://discord.com/channels/1354881461060243556)). The [public Marin Discord archive](https://marin-discord.pages.dev/) was exported through its read-only SQL viewer on 2026-09-22. It contained 36,257 messages across 75 text channels and their threads. Two forum channels were reviewed separately in the Discord app on 2026-09-23. Dates below use UTC; messages can have a September 23 UTC date while the archive export was made on September 22 Pacific time.

Each file synthesizes the main discussions and learnings visible in that channel, links claims to original messages, and provides monthly entry points for checking the wider history. A linked message may itself be in a thread; its replies are counted under the parent text channel. These are research notes, not an assertion that every proposal was implemented or every reported result reproduced. The archive does not include private DMs, deleted/unindexed messages, or the full contents of linked external artifacts.
